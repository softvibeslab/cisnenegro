# Inventario y elección de base

Instrucción portable creada para el paquete de Cisne Negro. No es una copia de la skill local `landing-inventory-first` ni prueba de una invocación histórica con este nombre.

## Cuándo usarla

Al empezar un sitio, landing o micrositio nuevo. Una corrección menor de un sitio existente no necesita repetir todo el inventario. Las instrucciones y preferencias explícitas del usuario tienen prioridad.

## Proceso

1. Identificar el workspace autorizado, el catálogo existente y el proyecto solicitado. Leer sus instrucciones y README; revisar el estado Git antes de modificar archivos. No asumir una ruta personal fija.
2. Registrar para cada candidato autorizado su actividad, audiencia, objetivo de conversión, stack, variante relevante y evidencia. La consulta de otros clientes se limita a clasificación y evaluación técnica; no leer sus archivos privados.
3. Comparar el nicho del encargo con los candidatos. Distinguir mismo nicho, relacionado, distinto y evidencia insuficiente. Una apariencia visual parecida no demuestra que los negocios sean equivalentes.
4. Si existe una base adecuada del mismo nicho, seleccionar componentes o patrones que ayuden al encargo. Mantener intacto el origen. Sustituir marca, contenido, contactos, analítica y configuración; no copiar credenciales, leads o datos operativos.
5. Si el nicho es nuevo, revisar referencias actuales de Envato Elements o ThemeForest y su compatibilidad. Registrar URLs, fecha, stack, utilidad y condiciones de incorporación. Una demo pública no concede el paquete comercial; usar solo archivos proporcionados con autorización y derechos suficientes.
6. Guardar la decisión dentro del nuevo proyecto: alcance, candidatos, comparación, base elegida y límites. Si una preferencia del usuario cambia la elección, documentarla sin bloquear el trabajo autorizado.
7. Entregar el registro a la fase de implementación y actualizar el catálogo cuando exista un resultado verificable. No declarar un sitio desplegado o validado solo por haber localizado sus archivos.

## Entregable breve

Crear `docs/base-del-sitio.md` con fecha, nicho, tabla de candidatos, evidencia y decisión. Evitar información comercial privada de otros proyectos. No descargar plantillas pagadas ni publicar sitios sin autorización dentro de la tarea.
